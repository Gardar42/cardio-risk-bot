# Telegram-ассистент для оценки риска сердечно-сосудистых заболеваний

Бот в Telegram, который в формате обычной переписки расспрашивает пользователя о его здоровье, оценивает риск сердечно-сосудистых заболеваний с помощью модели случайного леса и объясняет результат человеческим языком через большую языковую модель. Проект объединяет три части: классическое машинное обучение для предсказания, LLM для понимания ответов и интерпретации результата и Telegram-бота как интерфейс.

## Данные

Для обучения используется [Cardiovascular Disease dataset](https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset) с Kaggle: около 70 тысяч записей медицинских осмотров, целевая переменная — наличие сердечно-сосудистого заболевания. Датасет выбран потому, что все его признаки человек может сообщить о себе сам, без анализов и специальных обследований: возраст, пол, рост, вес, верхнее и нижнее давление, уровень холестерина и глюкозы (норма, выше нормы, значительно выше нормы), курение, употребление алкоголя и физическая активность. Классы сбалансированы примерно поровну.

Явных пропусков в данных нет, зато встречается много ошибок ввода: давление в несколько тысяч или отрицательное, рост 55 см, перепутанные местами верхнее и нижнее давление. Перепутанные значения меняются местами, а физически невозможные превращаются в пропуски и заполняются медианой по обучающей выборке. Возраст переводится из дней в годы, пол кодируется бинарным признаком, из роста и веса добавляется индекс массы тела.

## Как это работает

Пользователь отправляет боту /start и отвечает на одиннадцать вопросов своими словами. Каждый ответ передаётся языковой модели, которая извлекает из него значение: «метр восемьдесят» превращается в 180, «врач сказал, что немного повышен» — в уровень «выше нормы», «ага» — в «да». Если ответ непонятен, бот переспрашивает, а если пользователь говорит, что не знает ответа, вопрос пропускается и значение заполняется так же, как пропуски при обучении.

Собранные ответы передаются в обученную модель, которая возвращает вероятность заболевания. Эта вероятность вместе с данными пользователя уходит в LLM с системным промптом вежливого медицинского ассистента. Модель сообщает уровень риска, отмечает показатели, на которые стоит обратить внимание, даёт общие рекомендации по образу жизни и советует обратиться к врачу, не ставя диагнозов. После этого можно продолжить разговор и задать уточняющие вопросы: бот помнит данные пользователя и свой первый ответ.

Языковая модель подключается через OpenRouter с помощью LangChain, по умолчанию используется google/gemini-2.5-flash-lite. Бот написан на aiogram 3.

## Структура проекта

train_model.ipynb содержит весь путь от сырых данных до сохранённой модели: разведочный анализ, очистку, обучение пайплайна из импутера и случайного леса с подбором гиперпараметров по ROC-AUC, оценку на тестовой выборке и сохранение в model.pkl. В llm.py собраны обращения к языковой модели: извлечение значений из ответов, итоговый ответ пользователю и продолжение диалога. В bot.py описаны вопросы анкеты, логика опроса и связь всех частей между собой.

```
├── train_model.ipynb
├── llm.py
├── bot.py
├── requirements.txt
└── .env
```

## Результаты

Случайный лес достигает ROC-AUC X.XX на отложенной тестовой выборке. Наиболее важными признаками оказались ПРИЗНАК_1, ПРИЗНАК_2 и ПРИЗНАК_3. Для этого датасета такой результат близок к типичному потолку: многие факторы риска (наследственность, питание, стресс) в данных просто не представлены.

Важно понимать, что бот выдаёт статистическую оценку, а не медицинское заключение, и не заменяет консультацию врача.

## Запуск

Установите зависимости из requirements.txt, скачайте cardio_train.csv с Kaggle и выполните train_model.ipynb, чтобы получить model.pkl. Затем скопируйте .env.example в .env, укажите ключ OpenRouter и токен бота от @BotFather и запустите python bot.py.
